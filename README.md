Personal Portfolio Website:-

This is my personal portfolio website, built as part of the Web Development project at Bosscoder School of Technology.


About the Project:-

The website introduces me and shows my education, skills, projects, hobbies and achievements in one page. It is made using only HTML and CSS.


Sections:-

  1.Home
  2.About Me
  3.Education
  4.Skills
  5.Projects
  6.Hobbies and Interests
  7.Achievements
  8.Contact


Technologies Used:-

  1.HTML5

  2.CSS3 (flexbox and grid)

  3.Git and GitHub

  4.Visual Studio Code


Features:-

  1.Navigation bar with smooth scrolling to each section

  2.Skill bars for showing skill levels

  3.Project and achievement cards

  4.Contact form with built-in validation

  5.Responsive layout for laptop, tablet and mobile screens

  1.Download or clone this repository.

  3.Open index.html in any web browser.
